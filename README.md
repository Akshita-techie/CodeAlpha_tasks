# CodeAlpha Python Programming Internship Tasks

## Overview

This repository contains my completed Python programming tasks as part of the CodeAlpha Python Programming Internship.

The purpose of these projects is to strengthen practical Python programming skills by working on simple, real-world applications and automation scripts. Through these tasks, I practiced important programming concepts such as variables, data types, lists, dictionaries, loops, conditional statements, functions, user input, file handling, random selection, regular expressions, and basic automation using Python libraries.

## Completed Projects

### Task 1 — Hangman Game

A simple text-based Hangman game developed using Python.

The program randomly selects a word from a predefined list and allows the player to guess the word one letter at a time. Correct guesses reveal the letters in their appropriate positions, while incorrect guesses reduce the available attempts.

**Key Concepts:**
- Random word selection
- Lists and strings
- User input
- While loops
- If-else conditions
- Tracking guesses
- Console-based interaction

### Task 2 — Stock Portfolio Tracker

A Python-based stock portfolio tracker that calculates the total investment based on manually defined stock prices and user-entered quantities.

The program uses a dictionary to store stock prices, accepts stock names and quantities from the user, calculates individual investments, and calculates the overall investment value. The result can also be saved to a text file.

**Key Concepts:**
- Dictionaries
- User input and output
- Basic arithmetic
- Loops
- Conditional statements
- File handling

### Task 3 — Task Automation with Python

A Python automation project designed to perform a repetitive file or text-processing task automatically.

The project demonstrates how Python can be used to reduce manual work by processing files and extracting useful information. The implementation uses Python libraries such as `os`, `shutil`, and `re`, depending on the selected automation task.

**Key Concepts:**
- File handling
- Folder and file management
- Regular expressions
- Python automation
- Working with text files
- Built-in Python libraries
